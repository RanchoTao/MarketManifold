# 《基于动态网络与聚类分析的标普500市场结构演化研究》答辩提纲

## 第1页：研究背景

- **标题**：为什么要研究市场结构演化？
- **主要内容**：标普500不是静态股票集合，而是由收益、风险、行业和相关网络共同构成的动态系统。
- **讲解要点**：传统资产分类只能回答“哪些股票相似”，本项目要回答“市场处于什么状态、状态如何变化”。

## 第2页：研究问题

- **标题**：从股票聚类到市场状态发现
- **主要内容**：四个问题：是否存在市场状态、状态如何随时间变化、重大事件是否导致突变、聚类能否自动发现状态。
- **讲解要点**：强调聚类对象已经从股票改为滚动时间窗口。

## 第3页：数据集与时间窗口

- **标题**：2018/2020年至今的动态窗口设计
- **主要内容**：默认使用 2020-01-01 至 2025-06-30；60 个交易日窗口；20 个交易日步长。
- **讲解要点**：每个窗口是一个市场快照，类似把市场拍成连续影片，而不是只拍一张静态照片。

## 第4页：数据兜底与可复现性

- **标题**：真实数据优先，模拟数据兜底
- **主要内容**：若存在 `data/raw/sp500_prices.csv` 则直接读取；否则生成可复现实验数据。
- **讲解要点**：说明当前仓库无 API 权限，因此用可复现模拟面板保证实验闭环；替换真实数据不影响代码路径。

## 第5页：特征工程：收益与风险

- **标题**：从价格序列到市场级收益风险特征
- **主要内容**：平均收益、中位收益、收益标准差、年化波动率、最大回撤。
- **讲解要点**：收益描述方向，波动与回撤描述压力；二者共同区分牛市、调整和危机。

## 第6页：特征工程：横截面与行业结构

- **标题**：市场内部是否分化？
- **主要内容**：收益离散度、波动率离散度、行业集中度、行业收益标准差、行业收益差、科技相对市场收益。
- **讲解要点**：行业分化高时，市场可能不是全面上涨，而是由特定行业驱动。

## 第7页：动态相关网络

- **标题**：用网络刻画市场共同运动
- **主要内容**：每个窗口计算股票收益相关矩阵，构建阈值相关网络，提取平均度数、网络密度、聚类系数。
- **讲解要点**：危机中相关性上升，网络更紧密，分散化保护可能下降。

## 第8页：聚类方法设计

- **标题**：自动发现市场状态
- **主要内容**：比较 KMeans、Agglomerative Clustering、Gaussian Mixture；搜索 K=2 至 K=6。
- **讲解要点**：不同算法偏好不同簇形状；多算法对比比单一 KMeans Demo 更可信。

## 第9页：评价指标

- **标题**：如何选择最佳状态数？
- **主要内容**：Silhouette Score、Davies-Bouldin Index、Calinski-Harabasz Index。
- **讲解要点**：不是凭感觉命名状态，而是先由指标选择候选模型，再解释各状态经济含义。

## 第10页：市场状态画像

- **标题**：从 Cluster 编号到可解释 Regime
- **主要内容**：展示 `results/regime_profiles.md` 中的自动命名状态，如危机共振、低波动牛市、高波动调整、科技成长驱动。
- **讲解要点**：逐一解释收益、风险、相关性、网络密度和行业结构差异。

## 第11页：动态演化时间轴

- **标题**：2020 至 2025 市场状态如何切换？
- **主要内容**：展示 `results/figures/regime_timeline.svg` 和 `results/regime_transition.csv`。
- **讲解要点**：说明状态不是一次性标签，而是随时间切换的市场结构序列。

## 第12页：关键事件突变检测

- **标题**：COVID、加息周期、AI 行情附近是否发生结构变化？
- **主要内容**：展示 `results/event_change_analysis.md` 的事件窗口分析。
- **讲解要点**：COVID 通常对应高相关、高波动状态；加息周期对应调整状态；AI 行情体现科技行业相对优势。

## 第13页：可视化结果

- **标题**：多视角展示市场结构
- **主要内容**：PCA 散点图、t-SNE 风格散点图、状态转移图、网络结构图、关键时期结构对比图。
- **讲解要点**：PCA/t-SNE 展示状态可分性，网络图展示相关结构，时间轴展示演化。

## 第14页：应用价值

- **标题**：研究结果能做什么？
- **主要内容**：风险监控、市场复盘、组合再平衡、行业轮动识别、宏观事件影响评估。
- **讲解要点**：本项目不是预测明天涨跌，而是建立市场状态识别和解释框架。

## 第15页：局限与未来工作

- **标题**：如何继续提升？
- **主要内容**：接入真实复权价格、加入真实 GICS 权重、市值权重、MST/社区发现、HMM/变点检测、统计显著性检验。
- **讲解要点**：主动说明模拟数据兜底和标准库实现的限制，未来可升级为真实数据和更强模型。

## 第16页：总结

- **标题**：核心贡献
- **主要内容**：完成从静态股票聚类到动态市场结构挖掘的重构；形成数据、特征、模型、评价、解释、演化和展示闭环。
- **讲解要点**：最后用一句话收束：项目研究的是“市场结构如何形成和改变”，不是简单给股票贴标签。
