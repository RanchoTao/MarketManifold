# 现场答辩展示提纲

## 第1页：研究背景与问题定义

- **核心内容**：标普500包含大量资产，单一收益率无法解释市场结构；项目希望用聚类发现相似资产群体。
- **建议配图**：标普500或市场网络示意图，或前端圆环态截图。
- **讲稿要点**：本项目不是预测股价，而是做无监督数据挖掘，重点在结构发现、可解释画像和可视化展示。

## 第2页：数据集介绍

- **核心内容**：样本为 500 只标普500股票，当前仓库使用 `sp500_features.csv` 聚合特征表。
- **建议配图**：字段说明表。
- **讲稿要点**：说明字段包括股票代码、最新价格、1年收益率、1年波动率、6个月动量、1年最大回撤；强调原始数据来源和精确日期仍需人工补充。

## 第3页：数据范围与清洗规则

- **核心内容**：样本筛选、缺失值、异常值、重复值处理。
- **建议配图**：数据清洗流程图。
- **讲稿要点**：删除关键字段缺失样本，按 ticker 去重，对数值字段做 1%/99% 分位数截尾，避免极端值主导聚类。

## 第4页：技术路线

- **核心内容**：数据读取 → 清洗 → 特征工程 → 标准化 → KMeans → 指标评价 → PCA 可视化 → 聚类画像。
- **建议配图**：项目技术流程图。
- **讲稿要点**：突出从“提案”推进到“可复现实现”的变化：脚本、结果文件、图表和前端均已连通。

## 第5页：特征工程

- **核心内容**：收益强度、风险强度、时间趋势、稳定性/回撤四类特征。
- **建议配图**：四个特征的定义表或箱线图。
- **讲稿要点**：解释为什么不直接用最新价格聚类；价格量纲大但不代表市场行为相似性，因此只作为展示字段。

## 第6页：聚类方法

- **核心内容**：KMeans 的输入、距离含义、标准化处理、K 值搜索范围。
- **建议配图**：KMeans 原理示意图或二维点聚类图。
- **讲稿要点**：KMeans 适合连续数值特征和快速展示，但对异常值和非球形簇敏感，所以做了异常值截尾并保留改进方向。

## 第7页：评价指标

- **核心内容**：Silhouette Score、Davies-Bouldin Index、Calinski-Harabasz Index、SSE/Inertia。
- **建议配图**：`results/figures/k_metrics.svg`。
- **讲稿要点**：说明每个指标方向：Silhouette 越大越好，DBI 越小越好，CH 越大越好，SSE 用肘部法观察下降趋势。

## 第8页：实验结果

- **核心内容**：展示 `results/metrics.csv` 的关键 K 值对比，并说明默认展示 K=8。
- **建议配图**：K 值评价图和指标表局部截图。
- **讲稿要点**：强调最终 K 的选择综合考虑指标、画像数量和现场解释性，而不是机械选择单一指标最优。

## 第9页：二维可视化

- **核心内容**：PCA 二维聚类散点图和前端收益率—波动率结构图。
- **建议配图**：`results/figures/pca_cluster_scatter.svg` 与前端市场结构态截图。
- **讲稿要点**：PCA 用于降维观察聚类边界，前端用于交互式探索股票位置和同类连线。

## 第10页：聚类画像/类别画像

- **核心内容**：展示 8 个可解释类别，如低波动稳健型、高风险下行型、高收益稳健动量型等。
- **建议配图**：`results/figures/cluster_feature_bar.svg` 或 `results/cluster_profile_summary.csv` 表格。
- **讲稿要点**：不要只读 Cluster 编号，要说明各类的收益、波动、动量和回撤特征，以及代表股票。

## 第11页：应用价值

- **核心内容**：资产分层、推荐系统、精准运营、风险管理、财经内容理解。
- **建议配图**：应用场景四象限图。
- **讲稿要点**：聚类结果可以作为资产标签，用于帮助用户理解市场结构、发现相似资产和识别高风险类别。

## 第12页：前端现场演示

- **核心内容**：打开 React 看板，展示圆环态、市场结构态、K 值切换、股票搜索和特征表排序。
- **建议配图**：现场直接运行页面；备份截图。
- **讲稿要点**：建议搜索 AAPL、AMZN、AMD、MU 等股票，演示它们在图中的位置和所属类别。

## 第13页：局限与改进方向

- **核心内容**：原始数据缺失、时间窗口待确认、特征维度有限、算法可扩展。
- **建议配图**：局限与改进表。
- **讲稿要点**：主动说明不足能体现严谨性；后续可补充行业、市值、成交量、文本情绪和稳定性检验。

## 第14页：总结

- **核心内容**：项目完成了从数据到模型、指标、画像和展示的闭环。
- **建议配图**：整体流程闭环图。
- **讲稿要点**：用一句话总结：本项目用无监督学习将标普500股票转化为可解释的市场结构类别，并通过前端可视化支持现场展示。
