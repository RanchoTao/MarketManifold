# 真实市场数据来源说明

## 1. 数据来源

本项目真实行情数据来自 Yahoo Finance，并通过 Python `yfinance` 包下载。下载脚本为 `src/fetch_market_data.py`，请求参数使用 `auto_adjust=True` 和 `interval="1d"`，因此价格字段采用自动复权后的日频收盘价。

## 2. 下载日期

数据下载脚本会在 `results/data_download_summary.json` 中记录 UTC 下载时间 `download_timestamp`，并在 `results/data_download_log.txt` 中保存批次、重试和失败信息。

## 3. 时间范围

本次默认样本区间为 `2021-06-23` 至 `2026-06-23`。由于 Yahoo Finance / yfinance 的 `end` 参数通常是右开区间，脚本实际请求的结束参数为 `2026-06-24`。

## 4. 股票池定义

股票池不从当前网页临时抓取完整标普500成分股，而是使用项目固定配置 `src/market_config.py` 中的 `SECTORS` 字典。该字典包含约 104 只代表性标普500股票，覆盖 11 个 GICS 一级行业，并与主流程 `src/dynamic_market_regime.py` 共享同一份配置，避免行业标签和股票池不一致。

## 5. 自动复权含义

`auto_adjust=True` 表示 yfinance 会将历史 OHLC 价格按拆股和股息等公司行为进行调整。项目使用调整后的 `Close` 作为 `close` 字段，以提高跨年度收益率和滚动窗口特征的可比性。

## 6. 数据字段

最终主流程输入文件为：

```text
data/raw/sp500_prices.csv
```

必须包含字段：

| 字段 | 含义 |
| --- | --- |
| `date` | 交易日期，格式 `YYYY-MM-DD` |
| `ticker` | 项目内部统一股票代码 |
| `sector` | 来自 `SECTORS` 的行业标签 |
| `close` | 有限且大于 0 的自动复权收盘价 |

## 7. 缺失值处理

清洗流程使用成功下载股票日期的并集作为交易日基准，不自行生成普通工作日。对同一 `date + ticker` 的重复记录保留最后一条有效记录。缺失、非数字、无穷值和 `close <= 0` 的价格记录会被删除。

## 8. 股票筛选规则

脚本先计算每只股票在基准交易日上的原始覆盖率，默认保留覆盖率不低于 95% 的股票。对保留股票最多只向前填充连续 2 个交易日，且不做反向填充，因此不会填充股票上市前或数据开始前的长期空白。填充后构造共同日期面板，只保留所有保留股票都有有效价格的交易日，确保主流程读取时每只股票日期集合一致。

## 9. 数据限制

- Yahoo Finance 是便捷行情源，但不是官方交易所数据库，可能存在修订、延迟、接口限制或临时下载失败。
- 当前股票池是代表性样本，不是完整历史标普500成分股。
- 固定使用当前项目股票池会带来幸存者偏差，不能代表无偏历史成分股研究。
- 本项目输出仅用于课程数据挖掘、市场结构聚类和可视化展示，不能据此作为投资建议。
